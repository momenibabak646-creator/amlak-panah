# املاک پناه

اپلیکیشن اندرویدی مدیریت دفتر املاک با Flutter، رابط فارسی راست‌چین و اتصال ابری Supabase.

## امکانات فعلی
- ورود و ثبت‌نام کاربران با Supabase Auth
- داشبورد شمارش فایل‌ها، مشتریان و پیگیری‌ها
- ثبت، ویرایش و حذف فایل ملک با کد فایل
- مشخصات ملک: نوع معامله، شهر، محله، آدرس، متراژ، قیمت، رهن، اجاره، اتاق، سن بنا، امکانات، وضعیت، مالک و تلفن
- ثبت کمیسیون، سهم مشاور، قابل‌مذاکره بودن قیمت و یادداشت محرمانه دفتر
- انتخاب چند تصویر، بارگذاری در فضای ابری، نمایش گالری و حذف تصویر
- OCR فارسی آفلاین از تصویر آگهی با متن قابل بازبینی و اصلاح، تشخیص فیلدهای متداول و تکمیل فرم پیش از ذخیره
- جستجوی فایل و فیلتر نوع ملک، معامله، بازه قیمت و متراژ
- اشتراک‌گذاری فایل با مشاوران توسط مدیر دفتر
- دعوت مشاور از پنل مدیر با دعوت‌نامه ایمیلی از طریق Supabase Edge Function
- ثبت و ویرایش مشتری و جستجو بر اساس نام، تلفن و نوع درخواست
- ثبت پیگیری مرتبط با مشتری و ملک و تغییر وضعیت آن
- گزارش تعداد فایل‌ها بر اساس وضعیت و جمع کمیسیون و سهم مشاور
- کش محلی حساب‌محور برای نمایش آخرین داده‌های خوانده‌شده در قطعی موقت شبکه

## موارد باقی‌مانده پیش از انتشار عمومی
- OCR این نسخه مبتنی بر Tesseract آفلاین است و هوش مصنوعی مولد برای تشخیص دقیق همه قالب‌های آگهی به آن متصل نشده؛ خروجی باید توسط مشاور بازبینی شود.
- تکمیل و آزمون میدانی گردش‌کار دعوت مشاور و اشتراک فایل با چند حساب واقعی.
- فعال‌سازی تنظیم Supabase برای جلوگیری از رمزهای افشاشده (Leaked Password Protection).
- ساخت و نگهداری کلید اختصاصی امضای انتشار خارج از مخزن و تولید APK با همان کلید.
- آزمون نهایی روی چند گوشی اندرویدی و بررسی بازیابی/پایداری داده‌ها در قطع اینترنت.

## امنیت و پیکربندی
آدرس Supabase و کلید publishable در lib/app_config.dart قرار دارند. کلید service_role در برنامه موبایل قرار نمی‌گیرد. کنترل دسترسی رکوردها و تصاویر با RLS و Storage policy انجام می‌شود. توابع حساس مدیر در schema خصوصی نگهداری شده‌اند.

## اجرای محلی
~~~bash
bash scripts/prepare_ocr.sh
flutter pub get
flutter run
~~~

## ساخت اندروید
~~~bash
flutter create --platforms=android --project-name=amlak_panah .
bash scripts/prepare_ocr.sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
~~~

GitHub Actions پس از هر Push به شاخه main تحلیل کد، تست‌ها و ساخت APK در حالت Debug و Release را اجرا می‌کند. خروجی Release-mode تا زمانی که با کلید اختصاصی انتشار امضا نشده، نسخه نهایی فروشگاهی محسوب نمی‌شود.
