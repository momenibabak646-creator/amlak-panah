# املاک پناه

اپلیکیشن اندرویدی مدیریت دفتر املاک با Flutter و رابط فارسی راست‌چین.

## امکانات پیاده‌سازی‌شده
- ورود و ثبت‌نام با حساب کاربری Supabase
- داشبورد شمارش فایل‌ها، مشتریان و پیگیری‌ها
- ثبت، ویرایش و حذف فایل ملک
- مشخصات ملک شامل نوع معامله، شهر، محله، آدرس، متراژ، قیمت، ودیعه، اجاره، اتاق، سن بنا، امکانات، وضعیت، مالک و اطلاعات تماس
- انتخاب و بارگذاری چند تصویر برای هر فایل در فضای ذخیره‌سازی Supabase
- جستجوی متنی فایل‌ها و فیلتر نوع ملک و معامله
- ثبت و ویرایش اطلاعات مشتری
- ثبت پیگیری مرتبط با مشتری و ملک و تغییر وضعیت پیگیری
- گزارش پایه وضعیت فایل‌ها
- نمایش فهرست کاربران برای مدیر دفتر
- کش محلی حساب‌محور برای نمایش اطلاعات ذخیره‌شده در صورت اختلال موقت شبکه

## مواردی که برای انتشار عملیاتی هنوز نیاز به تکمیل/تأیید دارند
- مدیریت کامل کاربران و دعوت/ساخت حساب مشاور از پنل مدیر
- گردش‌کار کامل اشتراک فایل بین مشاوران و سیاست‌های دسترسی آن
- نمایش گالری تصاویر ذخیره‌شده و مدیریت/حذف تصاویر در صفحه جزئیات ملک
- استخراج واقعی اطلاعات آگهی از تصویر با OCR/هوش مصنوعی و فرم بازبینی قابل ویرایش پیش از ذخیره
- جستجوی بازه‌ای پیشرفته و گزارش‌های مالی/کمیسیون
- بررسی نهایی سیاست‌های امنیتی RLS و Storage روی پروژه واقعی
- امضای APK با کلید اختصاصی انتشار و نگهداری امن آن خارج از مخزن

## پیکربندی
آدرس Supabase و کلید publishable از `lib/app_config.dart` خوانده می‌شوند. کلیدهای `service_role` یا secret هرگز نباید در برنامه موبایل قرار بگیرند. امنیت داده‌ها باید با RLS و Storage policies محدود شود.

## اجرای محلی
```bash
flutter pub get
flutter run
```

## ساخت اندروید
```bash
flutter create --platforms=android --project-name=amlak_panah .
flutter pub get
flutter test
flutter build apk --release
```

GitHub Actions پس از هر Push به شاخه `main`، کد را تحلیل و تست کرده و هر دو خروجی Debug و Release-mode APK را به‌صورت artifact بارگذاری می‌کند. خروجی Release-mode فعلی کاندیدای نصب و آزمون است و تا زمان امضای اختصاصی و تکمیل موارد بخش بالا، نباید نسخه نهایی انتشار عمومی/فروشگاهی تلقی شود.
