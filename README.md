# املاک پناه

اپلیکیشن مدیریت فایل‌های املاک با Flutter.

## امکانات نسخه فعلی
- ثبت فایل ملک (آپارتمان، ویلا، زمین، مغازه و دفتر کار)
- ویرایش و حذف فایل
- جستجو بر اساس عنوان، محله و شماره تماس
- نمایش متراژ، قیمت و اطلاعات تماس
- ذخیره اطلاعات روی خود گوشی؛ با بستن برنامه فایل‌ها باقی می‌مانند
- رابط کاربری فارسی و راست‌چین

## وضعیت اتصال سرور
ذخیره‌سازی فعلی محلی است. اتصال Supabase برای همگام‌سازی آنلاین و ذخیره تصاویر در مرحله بعد انجام می‌شود. اطلاعات محرمانه و کلیدهای Supabase نباید در مخزن عمومی ثبت شوند.

## اجرا
```bash
flutter pub get
flutter run
```

## ساخت APK
```bash
flutter create --platforms=android --project-name=amlak_panah .
flutter pub get
flutter build apk --release
```

گردش‌کار GitHub Actions نیز پس از هر Push، تحلیل کد، تست و ساخت APK آزمایشی را انجام می‌دهد.
